# Coping Skills Log

Source: © TherapistAid.com (2023) — search "Coping Skills Log" on therapistaid.com to download the original worksheet.

## Structure

Tracks a single coping skill you're practicing. Each entry captures a before/after snapshot:

- **Coping skill being practiced** (header)
- **Before:** situation, thoughts, emotions with intensity (1–10)
- **After:** results, emotions with intensity (1–10)

## Usage Notes

- Pick one coping skill to practice for at least a week before switching
- Intensity ratings are subjective — just be consistent with your own scale
- A skill "working" doesn't mean emotions go to zero. A drop of 2–3 points is meaningful.
- If a skill consistently doesn't move the needle after several tries, try a different one
- Good coping skills to start with: HALT check-in, 10-minute walk, journaling, thought defusion, feelings wheel check-in
